\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
The local hardware market in Gulhaji Plaza, Peshawar, suffers from significant
information asymmetry, where buyers face complex technical specifications and
opaque pricing, while vendors lack digital tools for transparent inventory
management. This capstone project presents an AI-powered laptop recommendation
and marketplace web application that addresses these challenges through a modern,
scalable microservices architecture.

The system employs a Content-Based Filtering recommendation engine using weighted
Cosine Similarity with feature vectorization, achieving a Precision@3 of 0.933 on
a validation set, exceeding the 0.85 target. The platform is built on a Tri-Stack
Microservices Architecture consisting of a React Progressive Web App (PWA)
frontend, a Node.js/Express API Gateway with JWT authentication and ACID-compliant
transactions, and a Python/FastAPI AI compute service. The system is fully
containerized using Docker and is designed for serverless deployment on Google
Cloud Platform (GCP) Cloud Run.

Empirical evaluation through load testing with k6 confirms a p95 latency of
28.77 ms at 100 concurrent users, with zero failures. An OWASP ZAP security scan
identified zero high-severity vulnerabilities. This research-grade thesis
documents the complete engineering process, culminating in a production-ready
solution that reduces search costs and builds trust in the local IT market.
